# Build playbook (figure-it-out run 1)

This run builds Gate A and Gate B from [DESIGN.md](DESIGN.md). Gates C and D get their own runs, because each one depends on what the previous gate measures.

## Phase A. Frame

### Definition of done (falsifiable)

**Gate A passes when all four hold on real artifacts:**

1. A signed menu-bar app runs focus, AX, event-tap, ScreenCaptureKit, HEVC encoding and still capture for 8 hours, including one stop/start and one sleep/wake. The soak report shows memory growth, dropped-observation counters, and clean teardown. Pass needs every collector still producing events at hour 8.
2. `just bench`-style measurement output exists for the three workloads (static reading, coding with builds, video), with CPU, memory, combined upload bytes, and still legibility checked by one server OCR engine. Energy uses `top -stats power`, since `powermetrics` needs sudo. Each number goes through the benchmark checklist before we report it.
3. `hx-schema` defines envelope v1 and the connector protocol, with JSON Schema exported, and property tests prove the dedup, clock and interval rules.
4. Fixtures from T3 (`orchestration_events`), Codex, Claude Code and Apple Bridge exist under `fixtures/`, are produced by a rerunnable extractor script, and parse against envelope v1.

Any item can come back **fail** or **unknown**. Unknown is not a pass.

**Gate B passes when a script replays a recorded session through the whole pipeline (outbox, ingest, compile, day view) and proves all of the following:**

- Duplicates, network loss, agent restarts and reordered delivery all produce the same timeline.
- Gaps show up as `coverage_unknown`.
- Durations match the scripted ground truth to within 1 s for every observable transition.

### Scope

| Part | Rough size | Effort (agent-time) |
|---|---|---|
| Scaffold (git, toolchain, workspace, lints, CI script, Postgres compose) | small | 1 h |
| `hx-schema` contract + property tests | ~1.5k lines | 3 h |
| Native spike (`hx-macos-sys`, `hx-agent`, `hx-agent-app`) | ~3 to 4k lines | 8 to 12 h, plus an 8 h soak |
| Measurement harness + report | ~0.5k lines | 3 h, plus workload runtime |
| Fixture extractor | ~0.6k lines | 2 h |
| Gate B (outbox, uploader, ingest, store, compiler, browser extension, T3 adapter, day view, chaos replay) | ~6 to 8k lines | 15 to 20 h |

These are guesses, not measurements. The total is roughly 2 to 3 days of agent-time plus the soak.

### Blockers found while grounding

1. **No Rust toolchain on this Mac.** `rustup` installs at user level with no sudo (~1.5 GB).
2. **Disk.** 28 GB free. Rust `target/` folders reach 5 to 10 GB, and parallel worktrees multiply that. Mitigation is one shared `CARGO_TARGET_DIR`, at most two worktrees at a time, and `cargo clean` between gates.
3. **Code signing.** The `Apple Development` identity is in the keychain. The first `codesign` can pop a keychain-access prompt, and the user's rules forbid triggering prompts. The user signs the first build by hand once (clicking "Always Allow"), or we stop at an unsigned build.
4. **macOS permissions.** Screen Recording, Accessibility and Input Monitoring have to be granted by the user in System Settings. Nothing here can grant them.
5. **No git repo yet.** `git init` is local and reversible. Pushing to GitHub is outward-facing, so it waits for the user.

### Rigor: high

The envelope contract and the capture agent are one-way doors. Wrong clock or identity fields can't be retrofitted onto data already captured, and a capture bug silently loses days that can't be re-recorded. So the gates add these artifacts:

- `/architect` (with arena) on the envelope and connector protocol.
- `/statechart` (TLA+) on the connector checkpoint and revision-publish protocol.
- `/interrogate` on the frozen contract before Gate B builds on it.
- Every measured number goes through `/benchmark-checklist`.
- Every delegated unit gets an independent judge, reading the diff and rerunning the check.

Mechanical units, like the scaffold and the extractor, get plain verification only.

## Phase B. Workflow

Riskiest unknowns come first. The scaffold and the harness land before the features they check.

| # | Unit | Depends on | Who | Check that ends it |
|---|---|---|---|---|
| 0 | Scaffold: `git init`, rustup, cargo workspace, `clippy -D warnings`, `cargo deny`, `scripts/check.sh`, Postgres in compose | none | me | `scripts/check.sh` green on an empty workspace |
| 1 | `/architect` + arena on envelope v1 and connector protocol (Opus vs. a second seat) | 0 | architect panel | types compile; one chosen design, logged with what was grafted from the loser |
| 2 | `hx-schema` implementation, JSON Schema export, proptests (dedup key, half-open intervals, monotonic durations, clock-step splits, DST days) | 1 | poteto-agent (Opus xhigh, subtle invariants) | proptests green; the schema files are generated by a test, not by hand |
| 3 | `/statechart` on cursor/checkpoint/backfill and revision publish | 1 | me | TLC finds no violation, or the counterexample becomes a contract change |
| 4 | `/interrogate` the contract | 2, 3 | Opus + second seat | every surviving finding is fixed or explicitly rejected in the log |
| 5a | Native spike: run-loop ownership, focus, AX with deadlines, event tap ring, SCK, VideoToolbox HEVC, stills, signed .app, collector health | 2 | poteto-agent, worktree (Opus xhigh, the hardest unit) | app runs 10 min with all collectors emitting envelope v1 into the local outbox; a judge reruns it |
| 5b | Fixture extractor for T3/Codex/Claude/Apple Bridge | 2 | delegate, worktree (Sol medium) | `fixtures/` regenerates byte-identically; every row parses as envelope v1 |
| 6 | Measurement harness: workload scripts, `top`-based CPU and power sampler, byte counters, still legibility via one OCR engine | 5a | me | baseline numbers recorded for an idle machine before the agent runs |
| 7 | Gate A soak (8 h) + 3 workloads + report with pass/fail/unknown | 5a, 6 | me, user grants permissions | `docs/gates/gate-a.md` with every number vetted |
| 8 | **Checkpoint with the user on Gate A results.** A failed budget triggers a feasibility report, not silent tuning. | 7 | user | user reads the report |
| 9 | Gate B: outbox + uploader | 7 | delegate (Sol) | chaos test: kill -9 mid-upload loses nothing and duplicates nothing |
| 10 | Gate B: server ingest + store (axum, sqlx, Postgres) | 2 | delegate (Sol), parallel with 9 | integration test with duplicate, reordered, and late batches |
| 11 | Gate B: `hx-compile` interval index | 2 | poteto-agent (Opus xhigh) | `/tdd` + proptests; scripted-trace durations within 1 s |
| 12 | Gate B: browser extension + T3 adapter | 5b, 10 | delegate (Sol) | Playwright run + fixture replay |
| 13 | Gate B: basic day view + end-to-end chaos replay script | 9 to 12 | me | the Gate B predicate above, run by one script |

Units 5a and 5b run in parallel because they share no files. Units 9 and 10 run in parallel for the same reason. Each delegate gets its own worktree, and everything shares one `CARGO_TARGET_DIR` because of the disk constraint. Nothing else fans out.

**Timebox:** Gate A gets 1.5 agent-days plus the soak wall-clock. At expiry it publishes pass/fail/unknown and stops. Gate B gets 2 agent-days on the same rule.
